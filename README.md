# Automation Testing of Local Web Application Using Playwright

Projekt testów automatycznych napisany w JavaScript przy użyciu frameworka Playwright.  
Projekt powstał podczas kursu na platformie Udemy i obejmuje testowanie podstawowych funkcjonalności aplikacji internetowej.

## Zakres testów
- Uwierzytelnianie użytkownika (logowanie i rejestracja)  
- Walidacja formularzy  
- Nawigacja między stronami  
- Obsługa i wyświetlanie danych użytkownika  

## Technologia
- JavaScript  
- Playwright  
- Page Object Model (POM)
